# TextLink

An underlined link.

## You provide

- `href` and the words.

## Rules

- A link is always underlined. Colour alone never marks one.
- The words say where it goes: "Read the case study", "selfmind.app". Never "here", never "link".
- No arrow after the text and no icon for an outside site.
- On a field it takes the field's text colour by itself.
