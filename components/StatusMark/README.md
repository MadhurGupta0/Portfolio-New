# StatusMark

A project's status as a shape and its word.

| `status` | mark | means |
| --- | --- | --- |
| `live` | lit round lamp | in production and reachable now |
| `shipped` | solid square | delivered to real users |
| `built` | open square | complete, not publicly deployed |

## You provide

- `status`, and optionally a different word as `label`.

## Rules

- Always the mark and the word together. Never the mark alone.
- Only `live` uses `signal`. Do not colour the other two.
- One in each project entry, one in each case-study title block.
