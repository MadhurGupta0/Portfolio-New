# Ownership

Says whose work a project is, claim first.

## You provide

- One string. The first sentence is the claim ("Team-built." "Sole author.") and sets in bold. The rest names what was owned.

## Rules

- Every project entry and every case study has one.
- On team work, name what you owned in plain nouns: "the REST API, the billing pipeline". Never "we" for work that was yours, never "I" for work that was the team's.
- One or two sentences. It is a statement, not a paragraph.
