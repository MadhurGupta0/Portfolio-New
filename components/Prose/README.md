# Prose

Reading text: paragraphs, ticked lists, inline code, links.

## You provide

- Ordinary HTML: `p`, `ul`, `li`, `code`, `a`, `strong`.

## Rules

- Lines stay under `measure`.
- `code` is for text that is literally code: an identifier, a path, a command, a status line. Not for product names, not for numbers.
- Emphasis is weight 600. The family has no italic; do not fake one.
- A list takes a short tick, not a bullet, and each item is a full sentence.
