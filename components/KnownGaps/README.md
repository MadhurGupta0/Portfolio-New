# KnownGaps

What is not done yet, written down. It is dashed because on a drawing a dashed line is an edge that is not built.

## You provide

- `items`: one plain sentence each.
- `title`: defaults to "Known gaps".

## Rules

- Every case study of unfinished or unshipped work has one, inside its verification section.
- State the gap. Not an apology and not a plan: "The adaptive quiz path is not implemented."
- If there are no gaps, leave the component out. Do not write "None".
- The dashed outline means not built yet everywhere in the system. Do not use it for anything else.
