# WorkIndex

Everything else, as a plain table: name and one sentence, area, what it is built with.

## You provide

- `projects`: `{ name, description, href, categories, techStack }` each.
- `caption`: the table's name for screen readers.

## Rules

- For work that earns a line, not a case study. If a row needs a schematic, it belongs in a `ProjectCard`.
- One sentence per description, starting with what the thing is.
- Give `href` only when there is somewhere public to go. A private repository is not a link.
- Below 720px each row stacks. Nothing is hidden.
