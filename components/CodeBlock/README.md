# CodeBlock

A short block of literal code.

## You provide

- The code, as a string.

## Rules

- A route table, a query, a signature, a package listing: under a screenful. Link to the file for anything longer.
- Never a screenshot of code.
- No syntax colours. The system has two inks and one signal, and none of them means "keyword".
- Long lines scroll sideways inside the block; the page never does.
