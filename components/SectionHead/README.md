# SectionHead

Opens a section of the home page: a heading, an optional sentence, an optional control on the right.

## You provide

- `title`, an optional `note`, an optional `id` for the nav links, and optional children for the right-hand side.

## Rules

- Two or three words, sentence case: "Selected work", "More work", "Experience".
- It is quiet on purpose. The project names under it are the large type.
- No numbering. The sections are not steps.
- It carries its own space above. Do not add more.
